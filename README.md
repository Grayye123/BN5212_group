# BN5212_group · Idea 1

**换一位阅片医生，胸片模型还能保持表现吗？**

本项目使用标准胸片分类模型，比较训练时是否包含某位主治医生关联的病例，对该医生测试病例上的表现有什么影响。模型只输入图像；医生匿名编号用于分组。我们研究的是对**报告来源标签**的适应能力，尚不能据此判断医生水平或证明因果关系。

## 两个人如何配合

一项任务对应一个 Issue。队友可以用自己的 GPT Pro 辅助研究或写代码，再把产物放入分支并发起 PR（提交修改供核查）。维护者根据 PR 的文件和版本记录收回结果，核查后合入 `main` 并更新交接。无需整理或共享整段私人聊天。

ChatGPT 的 GitHub 应用主要用于读取仓库；直接编辑和推送代码需使用具备权限的 Codex 或 GitHub 操作。各自账号需单独授权该仓库，不能假定队友的聊天结果会自动进入这里。[OpenAI 官方说明](https://help.openai.com/en/articles/11145903-connecting-github-to-chatgpt)

## 仓库保存什么

保存维护文档、经检查的代码、配置、汇总结果和图表。当前仓库为公开仓库；不上传原始胸片、报告全文、逐病人或逐检查的数据表、匿名医生映射、私人下载链接与密码、模型权重或本机聊天记录。原始数据权限与 GitHub 协作权限分别处理。

当前我们主要维护文档、任务状态、成果接收和交接，代码开发与训练等后续明确安排。第一版只提交维护文件；现有本地原始材料和旧分析脚本不随本次提交发布。

提交前由维护者检查文件清单、中文编码、文档链接和敏感内容，并核对远端版本。文档检查不代表完成实验复现。

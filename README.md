# BN5212 · 胸片模型的跨医生表现

**同一个胸片模型，换一位阅片医生关联的病例，表现会变吗？**

我们比较训练时包含或排除某位医生病例的两个模型，在同一批测试病例上的表现。

目前整理资料和维护项目，尚未训练模型。胸片暂不下载，源文件保持原样。

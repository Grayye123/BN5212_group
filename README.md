# BN5212 · 胸片模型的跨医生表现

**训练包含或排除某位医生关联病例，胸片模型表现会变吗？**

我们比较训练时包含或排除某位医生病例的两个模型，在同一批测试病例上的表现。

2026-10-08 已完成期末扩展：3 个医生组、3 个固定训练种子，共 18 个 ResNet18 模型，权重、测试预测和指标已核查。三个组的平均 AUROC 差值为 +0.051 / −0.032 / +0.041，九次比较的条件病人区间均包含 0，当前没有可靠的普遍增益证据。先读[期末实验报告](results/final_v1/REPORT.md)、[已训练模型说明](results/final_v1/MODEL_CARD.md)和[结果入口](results/final_v1/README.md)；当前接手进度见 [HANDOFF.md](HANDOFF.md)。

本轮仓库只交接实验、模型实现和研究报告。期末 PPT 与视频由小组之后另行商量；模型权重暂不提交。

期中第一版真实配对实验已完成：两组模型的测试 AUROC 为 0.673 / 0.677，当前没有稳定组间差异证据。**同学接手请先打开 [期中结果总文件夹](results/midterm_v1/README.md)**：指标、图表、7 分钟讲述稿与接手清单均已整理。代码见 [运行说明](code/README.md)。原始数据与模型权重保留在授权本地环境。

## 存储预算

| 保存方式 | 估算 |
| --- | --- |
| 课程 ZIP | 约 43.34 GB；压缩成员总计 43,334,031,377 字节，另有目录及文件头 |
| 全部 DICOM 解压 | 75,439,424,259 字节，约 75.44 GB |
| ZIP 与完整解压副本同时保留 | 约 118.78 GB，尚未计入训练副本和临时文件 |
| ZIP 逐成员解码并只保存小尺寸训练副本 | 建议预留 55–65 GB；尚未实施 |
| ZIP、完整 DICOM 和训练副本都保留 | 建议预留 135–150 GB；尚未实施 |

GB = 10^9 字节；GiB = 2^30 字节。5,534 张单通道 8-bit 的 512×512 未压缩像素约 1.45 GB。若每检查只留一张，最多 3,351 张，约 0.88 GB；最终可用正面片数仍未知。PNG/JPEG 实际大小取决于内容与压缩设置。

## 显存预算

本地 RTX 3060 Laptop 约 6 GB 显存。使用随机初始化 ResNet18、随机三通道输入、AdamW、AMP float16、全部参数更新，每设置运行三个更新步；没有下载预训练权重或使用真实胸片。

| 输入 / batch | 张量分配峰值 | 框架保留峰值 | 建议正式进程预算 |
| --- | --- | --- | --- |
| 224×224 / 16 | 0.46 GiB | 0.54 GiB | 约 2 GiB |
| 512×512 / 16 | 1.25 GiB | 1.58 GiB | 约 3–4 GiB |

环境记录：PyTorch 2.12.0+cu126，torchvision 0.27.0+cu126。峰值不包含整张显卡所有应用的占用；正式处理和增强也可能增加开销。两模型顺序训练，不同时驻留；这些数字是短时资源测试，不证明正式实验可完成或有何性能。

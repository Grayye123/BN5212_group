## 三个打包版本是同一批数据

`BN5212_MIMIC-CXR.zip`、`dataset.zip` 与四个 `data_subset*.zip` 的 5,534 个 DICOM 成员 **CRC32 集合完全一致**，检查编号集合也一致。差别只在目录层级与附带的 macOS 元文件：

- `BN5212_MIMIC-CXR.zip` 保留完整 MIMIC 路径 `files/pXX/pXXXXXXX/sXXXXXXX/<dicom_id>.dcm`，可直接与官方索引表关联，**建议以此为准**。
- `dataset.zip` 与四个 `data_subset*.zip` 为扁平化的 `pXXXXXXX/sXXXXXXX/` 结构，缺少 `pXX` 分片层。

即三份拷贝互为冗余，只需使用其中一份，另两份合计约 86 GB 可视为备份。

## 官方标签不在服务器上

服务器上**没有** `mimic-cxr-2.0.0-chexpert.csv.gz`、`negbio`、`mimic-cxr-2.0.0-metadata.csv.gz` 或 `split` 文件——CXR 目录下只有 DICOM、报告文本、索引页和上述三个索引表。因此：

- 官方 CheXpert / NegBio 标签目前不可用，除非另行从 PhysioNet 获取（需 credentialed access）。
- 官方 `metadata` 表不可用，**体位字段（ViewPosition）只能从 DICOM 头重新读取**。
- 官方 split 划分不可用，病人划分须自行生成。

## 限制

本次只读取了文件清单与索引表，**未验证任何像素内容**，也未核对报告文本与既有自定义标签的一致性。医生表记录的是检查关联的匿名医生编号，不等同于逐图独立打标者；据此得到的差异不能用于评价医生水平。

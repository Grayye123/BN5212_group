# 同学需要本地数据时，从哪里接手

更新：2026-09-27。**GitHub 是代码和公开结果入口，不是病例数据盘。** 以下是维护者已核实的文件位置，不是下载链接，也不代表同学已取得访问权限。本次仅更新说明，没有传输数据或开通账号。

## 先按任务选择材料

| 同学要做什么 | 需要什么 | 去哪里找 |
| --- | --- | --- |
| 制作 PPT、解释实验、展示结果 | 讲述稿、结果图、指标、方法 | 克隆仓库后打开 [结果文件夹](../results/midterm_v1/README.md)，无需本地病例数据 |

| 接续本次模型研究 | 已训练权重、配置、对应划分和授权影像 | 维护者本机小规模运行目录；权重另有本机归档，见下表 |
| 从头重建标签与划分 | 标注工作簿、审计输入、代码 | 维护者本机桌面工作簿、`out/audit/` 和仓库 `code/` |
| 重新训练或扩大实验 | 已授权原始影像、标签与划分、训练环境 | 向课程数据管理员确认个人访问方式；不能仅靠克隆仓库完成 |

## 同学具体怎么获得访问

1. **只做 PPT：** 使用 GitHub 公开材料即可，不需要向维护者索取胸片、报告或账号。
2. **确实需要病例数据：** 先说明具体用途和所需材料，联系维护者定位文件，再向课程数据管理员确认个人的数据访问资格与批准的获取方式。PhysioNet 要求每位使用者独立取得访问权，不能因同组或同课而直接共享数据；个人认证、培训和数据使用协议流程见 [官方 FAQ](https://physionet.org/about/faqs/)。
3. **使用课程服务器：** 管理员需确认该环境的合规访问安排，并提供同学自己的账号/权限与连接说明。服务器地址、用户名和连接方式通过适当的私下渠道提供，不在公开仓库记录。不要把维护者的密码、SSH 私钥、令牌或登录会话发给同学；能连上服务器不等于已获数据使用资格。
4. **使用本地派生标签、划分、预测或权重：** 先确认适用的受限共享流程，不能默认用群聊、网盘、私有 GitHub 或打包整个项目代替。PhysioNet 的 [MIMIC 衍生数据与模型指导](https://physionet.org/content/mimiciv/3.1/) 要求在与源数据相同的协议下通过 PhysioNet 共享。尚未确认本项目已有这样的共享入口。
5. **获取后核对：** 在同学自己的忽略目录放置经批准获取的材料，核对文件哈希与版本，按 [代码说明](../code/README.md) 指定自己的工作簿、数据盘和运行路径。新实验写入新目录，保留首版结果；不要照抄维护者的 Z: 假定一定可用。

目前待确认的是同学各自的数据授权、服务器账号及受限产物获取渠道；这些不阻塞 PPT 制作。仓库不会自动开通权限，也未提供任何包含凭证的数据下载链接。

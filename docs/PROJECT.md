### 汇报相关工作及本项目定位

- [He et al., CVPR 2016](https://openaccess.thecvf.com/content_cvpr_2016/html/He_Deep_Residual_Learning_CVPR_2016_paper.html)：残差连接支持深层视觉网络的优化，是选用 ResNet18 的方法来源；本项目不声称提出新架构。
- [Smit et al., EMNLP 2020](https://aclanthology.org/2020.emnlp-main.117/)：CheXbert 从放射学报告抽取标签，为图像监督学习提供标签来源；论文效果不能当作本课程子集的标签准确率。
- [Zech et al., PLOS Medicine 2018](https://journals.plos.org/plosmedicine/article?id=10.1371/journal.pmed.1002683)：胸片肺炎模型的跨医院表现与混杂提示分组评估的重要性。我们的医生关联组比较受其问题意识启发，但不是该论文的跨医院复现，也不能由该论文推断医生因果效应。

本项目贡献定位为固定病人划分、病例配对和重复种子的可执行比较研究；无新独立影像金标准，也无随机医生分配。

## 研究问题

对主治医生 A，比较训练中**包含 A 关联病例**与**排除 A 关联病例**的两个图像模型；两者都在同一批 A 的测试病例上评估。模型只输入图像，医生匿名编号用于分组。

先按病人隔离训练、验证和测试集。两组训练数量匹配，尽量平衡体位；共用不含 A 病例的验证集与相同训练设置。匹配后，包含 A 的组必须确实保留 A 的训练病例。

医生关联病例不是随机分配。病情、体位和报告抽取误差都可能影响差异；本实验不能直接判断医生水平或证明医生的因果作用。

## 流程与接口

```text
索引 + 标签 + 医生表 → 关联核查 → 获准后核查图像
→ 每检查按固定规则选一张正面片 → 按病人划分
→ 为每位纳入医生配对训练 → 同一套测试病例评估
```

| 函数 | 约定 |
| --- | --- |
| `build_manifest(index, labels, providers)` | 检查影像键唯一、标签和医生表每检查唯一；按检查多对一关联，核对病人编号；保留关联失败记录 |
| `define_target(data, policy)` | 保留原始四态及来源；缺失整行另行排除。草案：阳性 1，明确阴性/未提及 0，不确定排除 |
| `prepare_images(data, policy)` | 获准后读取完整 DICOM，核对体位、灰度转换和选片规则，记录排除原因 |
| `split_by_patient(data, policy)` | 同一病人及重复影像不跨集合；保存划分清单、种子和摘要值 |
| `make_reader_pair(train, valid, test, doctor)` | 匹配训练数量及体位，共用不含 A 的验证集与同一 A 测试集；核查独立正负例病人数 |
| `train_model(train, valid, config, seed)` | 草案用预训练 ResNet18 单输出；只用验证集选模型和阈值，不在测试集调参 |
| `compare_predictions(seen, unseen, test)` | 比较 AUROC、AUPRC、Brier；按病人配对重复抽样给出区间 |

## 期中第一版真实结果（2026-09-27）

**已完成、已核查、采纳为初版探索性结果。** 本机 `private/midterm_v1_quick/` 保存本次真实数据运行。两组 ResNet18 各完成 5 轮，分别按共享验证 BCE 选中第 3 / 4 轮；测试集为相同的 109 次检查、55 位病人、39 次阳性。

固定训练阳性率的概率基线：AUROC 0.500000 / AUPRC 0.357798 / Brier 0.245991。两模型的指标点估计均优于该基线，但未对“优于基线”另做显著性检验。配对 bootstrap 1,000 次全部有效；区间描述病人抽样不确定性，不包含重新训练的随机性。

结论：本次小规模实验未显示稳定的组间差异，不能称两组等效，也不能推断不存在医生关联差异。第一版已证明数据、训练与配对评估流程可以真实运行。仅一个医生关联组和一个种子，报告标签及自动规则仍可能有偏差，训练独立病人数和其他病例构成并未完全匹配。

核查：718 张所需真实图像均成功解码为非恒定 224×224 uint8 副本；109 行预测与测试键及标签逐项对应；训练/验证/测试病人隔离，分层数量匹配，清单哈希一致；原测试文件在预算调整前后逐字节一致。使用 NumPy 的阳阴例两两比较、排序平均精确率和均方误差独立重算三个指标，误差小于 1e-12。两份最佳权重文件已保存（约 44.8 MB/份），结果图已目视检查，无裁切或标签遮挡。

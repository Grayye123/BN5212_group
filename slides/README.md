## 汇报要求

- 小组提交，围绕一个选定任务展开。
- 每组 **7 分钟**；**四位成员都须汇报**，最好讲自己负责的部分。
- 分组与汇报顺序沿用 student-led learning session。

| 必需部分 | 应覆盖的内容 |
| --- | --- |
| 问题与动机 | 选定的机器学习任务，以及问题为什么有意义 |
| 相关工作 | 与任务和方法相关的文献 |
| 拟采用的方法 | 数据处理、模型、训练方法和评估指标；鼓励说明方法的新意 |
| 当前进展 | 初步数据分析，需有表格和/或图；如已有初步实现或结果，鼓励展示 |
